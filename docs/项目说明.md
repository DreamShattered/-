# 多动症矫正器 (FocusFreeze)

键鼠操作频率检测器。当你在设定时间内按键/点击过于频繁，它会**冻结当前程序**、**播放你指定的素材**并**遮挡屏幕**，强行打断无意识的高频操作。

最初为东方 Project 系列弹幕游戏做的适配工具，但适用于任何前台程序。

---

## 功能

**频率检测**
- 全局键鼠钩子（`WH_KEYBOARD_LL` / `WH_MOUSE_LL`），统计窗口与事件阈值可自由设定
- 触发后冷却时间可设，避免连续打断
- 按住按键的判定可调：**持续按住只算一次**（忽略系统自动重复），或**每按住 N 毫秒算一次**

**触发动作**
- **冻结前台程序**：挂起进程定格当前这一帧，或向游戏发送暂停键（让其自行暂停）
- **显示素材**：图片（按自身尺寸 1:1，上限屏高 1/3）、音频，或直接播放视频
- **遮挡屏幕**：高斯模糊 / 马赛克 / 纯色 / 仅暗化 / 自定义背景图，防止在暂停期间观察局势
- **安全阀**：定格期间按 `ESC` 立即恢复；程序退出或异常时强制恢复所有被挂起的进程

**素材管理**
- 支持从文件夹轮换选取（随机洗牌 / 顺序循环），一轮内不重复
- 图片与音频可**同名配对**（`A.png` ↔ `A.mp3`）或按顺序配对
- 视频素材可直接替代「图片+音频」，无需配对

## 构建

需要 .NET 8 SDK。

```bash
# 编译
dotnet build src/FocusFreeze.csproj -c Release

# 发布为单文件（自包含，目标机器无需安装 .NET）
dotnet publish src/FocusFreeze.csproj -c Release -r win-x64 \
  --self-contained true \
  -p:PublishSingleFile=true \
  -p:IncludeNativeLibrariesForSelfExtract=true \
  -p:EnableCompressionInSingleFile=true \
  -o publish
```

产物为 `publish/多动症矫正器.exe`，双击即用。首次运行会在同目录生成 `assets/`（默认提示图与提示音）与 `config.json`。

## 使用

详见 **[docs/使用说明.md](docs/使用说明.md)**。

简要流程：双击运行 → 调好阈值与素材 → 点「最小化并继续监控」→ 回游戏。触发时画面定格、素材出现；按 `ESC` 可立即恢复。

## 命令行工具

程序内置若干自检入口，输出写入 exe 同目录的文本文件，便于排查环境问题：

```bash
多动症矫正器.exe --selftest        # 环境 / 钩子 / 素材 / 权限 / 显示器自检
多动症矫正器.exe --probe 3000      # 频率检测 + 按键判定逻辑自检（含模拟用例）
多动症矫正器.exe --suspendprobe    # 挂起 / 恢复原语自检（读取线程状态对比）
多动症矫正器.exe --swallowcheck    # 吞键行为验证（按下被拦、抬起放行）
多动症矫正器.exe --plan            # 列出素材实测时长与算出的冻结 / 展示时长
多动症矫正器.exe --triggertest     # 启动 2 秒后自动触发一次（调试用）
```

## 技术要点

- **输入钩子**：低层钩子在系统输入链路上同步执行，回调内只做「写时间戳 + 计数」，数据落在无锁环形缓冲；钩子跑在独立线程的消息泵上
- **按键状态机**：区分「真实按下」与「系统自动重复」，并周期性用 `GetAsyncKeyState` 校正，避免 KEYUP 丢失导致状态卡死
- **定格与恢复**：`NtSuspendProcess` / `NtResumeProcess`；恢复后主动请求窗口重绘，修复部分 D3D 程序画面停住的问题
- **吞输入策略**：定格期间只屏蔽「按下」、放行「抬起」，否则前台程序会一直以为按键被按住
- **遮挡层**：全屏置顶窗口，点击穿透、不抢焦点；抓屏仅存内存，用完即断引用
- **时长解析**：`MediaPlayer` 预读素材长度并缓存，扫描文件夹后后台预热，触发时通常零等待

## 已知限制

1. **独占全屏游戏**：覆盖层不可见，挂起还可能黑屏——需先切窗口化 / 无边框窗口化
2. **时间跳变**：冻结时长跟随素材，若素材很长，老引擎恢复后可能快进追赶
3. **跨权限级别**：目标以管理员身份运行时，本程序也需要提权才能挂起它
4. **反作弊**：内核级反作弊的游戏不在适配范围内
