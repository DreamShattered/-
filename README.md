# 多动症矫正器

键鼠操作频率检测器。当你在设定时间内按键/点击过于频繁，它会**冻结当前程序**、**播放你指定的素材**并**遮挡屏幕**，强行打断无意识的高频操作。道理差不多是这样，但是装上了之后反而更想高频操作了是怎么回事呢。

最初为东方 Project 系列弹幕游戏做的适配工具，但适用于任何前台程序，基本是拷打ai写的，所以很可能质量不怎么样。

---

## 功能

**频率检测**
- 全局键鼠钩子（`WH_KEYBOARD_LL` / `WH_MOUSE_LL`），统计窗口与事件阈值可自由设定
- 触发后冷却时间可设，避免连续打断
- 按住按键的判定可调：**持续按住只算一次**（忽略系统自动重复），或**每按住 N 毫秒算一次**

**触发动作**
- **冻结前台程序**：挂起进程定格当前这一帧，或向游戏发送暂停键（让其自行暂停）
- **显示素材**：图片（按自身尺寸 1:1，上限屏高 1/3）、音频，或直接播放视频
- **遮挡屏幕**：高斯模糊 / 马赛克 / 纯色 / 仅暗化 / 自定义背景图，防止在暂停期间观察局势
- **安全阀**：定格期间按 `ESC` 立即恢复；程序退出或异常时强制恢复所有被挂起的进程

**素材管理**
- 支持从文件夹轮换选取（随机洗牌 / 顺序循环），一轮内不重复
- 图片与音频可**同名配对**（`A.png` ↔ `A.mp3`）或按顺序配对
- 视频素材可直接替代「图片+音频」，无需配对

**时间线**（跟随素材长度）
```
展示时长 = 素材时长 + 展示偏移 (-0.5 ~ +0.5 s)
冻结时长 = 素材时长 + 冻结偏移 (-0.5 ~ +0.5 s)   或固定秒数
遮挡持续到展示结束（游戏已恢复但屏幕仍被挡住）
```
