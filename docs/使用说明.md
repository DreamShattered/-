# 使用说明

多动症矫正器  (v1.4)
====================

（原名 FocusFreeze，内部命名空间沿用，不影响使用）

【它做什么】
检测键鼠操作频率，超过阈值后：
  1) 冻结你正在操作的程序，把画面定格在当下这一帧（时长可独立设定）
  2) 在屏幕中间偏下显示一张图片，并播放一段音频
  3) 游戏放开后，图片与音频继续留在屏幕上；到期自动收起
冻结期间按 ESC 可立即恢复。程序退出或异常时也会强制恢复所有被挂起的进程。

【v1.1 的三项改进】
1) 冻结时长与展示时长彻底分离
   - 「冻结游戏时长」默认 1.0 秒：游戏只损失很短的时间，恢复前后时刻差异被压到最小
   - 「图片展示时长」可独立设长，且支持三种方式：
       固定秒数 / 跟随音频时长 / 音频时长 + 额外秒数
     选「跟随音频时长」时，音频放完图片就收起，不用自己去数音频有几秒。
     界面右侧会显示当前音频的实际时长。
   - 恢复后会主动请求目标窗口重绘，避免个别 D3D 程序恢复后画面停住不刷新。
2) 冻结期间不再计数
   - 触发瞬间会清空滑动窗口并暂停计数，恢复后从零开始，
     不会因为冷却时间为 0 或残留计数而立刻重复触发。
3) 按住按键的判定可调
   - 「持续按住只算一次」：只算真正按下的那一下，系统的自动重复（一直按住会疯狂发按键）
     会被识别并忽略。这是默认。
   - 「按住算多次」：以按下的时长为判据，每按住 N 毫秒算一次操作，N 可自由设定。
4) 触发瞬间仍被按住的键不会被继续计数
   - 定格那一刻如果你正按着某个键（比如一直按着射击键），该键在你松开之前不再计入，
     松开后重新按下才恢复正常。同时按键状态会周期性用系统真实键状态校正，
     不会因为事件丢失而卡在「已按下」。
5) 定格期间只屏蔽「按下」，放行「抬起」
   - 原先定格期间会把键盘鼠标事件全部吞掉，导致你在定格时松开的那个键，
     游戏收不到「抬起」，于是一直以为你还按着，直到你再按一次才解除。
     现在改为：屏蔽新的按下、放行抬起，前台程序的按键状态永远不会残留。
     自检命令：FocusFreeze.exe --swallowcheck

6) 触发时遮挡画面（防止暂停期间观察局势）
   - 可选方式：不遮挡 / 高斯模糊 / 马赛克 / 纯色遮挡 / 仅暗化 / 自定义背景图。
   - 暗化程度可以叠加在任意方式之上（模糊+暗化是最强的组合）。
   - 「自定义背景图」用你自己上传的图片铺满屏幕，这个模式完全不抓屏。
   - 其余三种以画面为底的方式会抓取「触发瞬间」的整屏画面作为底图。
   - 游戏恢复运行的同时，遮挡自动撤除。

   关于抓取的画面去哪了：它只存在于程序内存里，用于遮挡显示，
   遮挡结束后立即断开引用交给 GC，全程不写入任何文件、不联网。
   实测数据：程序完整运行一轮（含触发）后，程序目录与临时目录新增文件数为 0。

7) 素材可以来自文件夹，并支持图片-音频绑定
   - 素材类型：图片+音频 / 视频（视频自带画面与声音，无需配对）
   - 素材来源：固定文件 / 文件夹随机（洗牌轮换，一轮内不重复）/ 文件夹顺序（按名称循环）
   - 配对方式：同名配对（A.png 配 A.mp3）/ 按顺序配对（第 N 张配第 N 个）/ 不配对
   - 文件夹模式的素材统计会显示在界面上（图片 N 张 / 音频 M 个 / 视频 K 段）

8) 时间线现在分三段，且时间长度都跟着音频走
   - 展示时长 = 音频(视频)时长 + 展示时间偏移（-0.5 ~ +0.5 秒）
   - 冻结时长 = 音频(视频)时长 + 冻结时间偏移（-0.5 ~ +0.5 秒），
     也可切回「固定秒数」。默认不设上限，完全跟随素材时长。
     （config.json 的 GameProfiles 里给某个程序写 SuspendCapSeconds > 0 可以单独限长。）
   - ① 冻结游戏（按上面的规则）
   - ② 游戏恢复运行，但遮挡仍然盖着：音频或视频继续播，使用者看不到局势。
   - ③ 展示结束：撤掉遮挡与素材。
   - 「遮挡持续到展示结束」默认开启；关掉它则游戏一恢复就撤遮挡。

9) 视频素材
   - 支持 mp4 / m4v / wmv / avi / mov / mkv / webm。
   - 可全屏铺满，也可按屏幕中间偏下的小窗显示（与图片位置一致）。
   - 默认等视频播完再收；期间按 ESC 仍可立即中止。
   - 视频文件损坏或缺少解码器时会自动回退到 图片+音频。


10) 图片按自身尺寸显示
   - 图片默认按原始尺寸 1:1 显示（不放大），只有超过上限时才等比缩小：
     宽度上限 = 屏幕宽的 80%，高度上限 = 屏幕高的 1/3。
   - 配合「画面垂直位置比例」默认 0.62，图片实际落在屏幕中偏下的三分之一范围内。
   - 这两个上限在 config.json 里是 MaxWidthRatio / MaxHeightRatio，可自行调整。

【怎么用】
1. 双击 FocusFreeze.exe。首次运行会在同目录生成 assets\notice.png 与 notice.wav。
2. 调参数，然后点「最小化并继续监控」，回游戏里玩。
3. 想验证效果就看界面底部「运行日志」：命中档案、冻结是否成功、错误码都会打印。

第一次测试建议把阈值调到 4~6 次 / 1000ms。

【定格方式】
- 挂起进程：画面停在当下这一帧（适合 th09 / th06nc）
- 发送暂停键：让游戏自己暂停（th10 风神录默认用这个，即 ESC 键）

已内置东方系列适配档案（th06/th07/th08/th09/th10/th11/th12/th06nc），
命中时自动套用该游戏推荐的定格方式与冻结上限，日志里会写明。

【注意】
1. 玩 th10 前把输入法切成英文：中文输入法会吃掉注入的字符键（Z 等）。
2. th10 必须从 Steam 启动，启动时弹出的模式框选 [ウィンドウ]。
   勾上「自动为东方风神录选择窗口模式」就不用每次手点。
3. 三个游戏实测都不是独占全屏，图片能正常盖在画面上；
   换成其它游戏若图片不显示，说明那是独占全屏程序，需先切窗口化。

【文件说明】
  多动症矫正器.exe   主程序（自包含 64 位，无需安装 .NET）
  config.json        全部参数，程序自动读写
  assets\            默认提示图与提示音，可替换

【命令行自检】
  多动症矫正器.exe --selftest        环境/钩子/素材/权限/显示器自检
  多动症矫正器.exe --probe 3000      频率检测 + 按键判定逻辑 自检
  多动症矫正器.exe --suspendprobe    挂起/恢复原语自检
  多动症矫正器.exe --swallowcheck    吞键行为验证（按下被拦、抬起放行）
  多动症矫正器.exe --triggertest     启动 2 秒后自动触发一次（调试用）
  多动症矫正器.exe --plan            列出素材实测时长与算出的冻结/展示时长（验证时长挂钩）
