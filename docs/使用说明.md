# 使用说明

**多动症矫正器 v1.6**（原名 FocusFreeze，内部命名空间沿用，不影响使用）

---

## 它做什么

检测键鼠操作频率，超过阈值后：

1. **冻结**你正在操作的程序，把画面定格在当下这一帧
2. 在屏幕中间偏下**显示一张图片**（或播放一段视频），同时**播放音频**
3. 程序放开后素材继续留着，到期自动收起

定格期间按 `ESC` 可立即恢复。程序退出或异常时也会强制恢复所有被挂起的进程。

---

## 定格方式

- **挂起进程**：画面停在当下这一帧，恢复后游戏接着走。推荐。
- **发送暂停键**：向目标程序发送一个按键（默认 `ESC`），让它自己暂停。键码在 `config.json` 的 `PauseKeyVirtualKey`。

**定格时长默认完全跟随素材长度，没有上限。**（旧版有个冻结上限，v1.6 已经去掉了 —— 不然素材一长，你只能干看着自己被弹幕揍飞。）

---

## 素材

- **类型**：图片+音频 / 视频（视频自带画面与声音，不用配对）
- **来源**：固定文件 / 文件夹随机（洗牌轮换，一轮内不重复）/ 文件夹顺序（按名称循环）
- **配对**：同名配对（`A.png` 配 `A.mp3`）/ 按顺序配对（第 N 张配第 N 个）/ 不配对
- **视频**：mp4 / m4v / wmv / avi / mov / mkv / webm。可全屏铺满，也可按屏幕中偏下的小窗显示；默认等播完再收；文件坏了或缺解码器会自动回退到「图片+音频」
- **图片**：默认按原始尺寸 1:1 显示（不放大），只有超过上限才等比缩小 —— 宽 ≤ 屏幕宽的 80%，高 ≤ 屏幕高的 1/3。配合「画面垂直位置比例」默认 0.62，实际落在屏幕中偏下的三分之一范围内
- 文件夹模式的素材统计会显示在界面上（图片 N 张 / 音频 M 个 / 视频 K 段）

---

## 时间线

```
展示时长 = 素材时长 + 展示偏移 (-0.5 ~ +0.5 s)
冻结时长 = 素材时长 + 冻结偏移 (-0.5 ~ +0.5 s)   或固定秒数
```

1. 冻结程序
2. 程序恢复运行，但**遮挡仍然盖着** —— 素材继续播，使用者看不到局势
3. 展示结束：撤掉遮挡与素材

「遮挡持续到展示结束」默认开启；关掉它则程序一恢复就撤遮挡。

---

## 触发时遮挡画面

防止在定格期间观察局势。方式：**不遮挡 / 高斯模糊 / 马赛克 / 纯色 / 仅暗化 / 自定义背景图**。

- 暗化可以叠加在任意方式之上（模糊 + 暗化是效果最强的组合）
- 「自定义背景图」用你自己的图片铺满屏幕，这个模式完全不抓屏
- 其余以画面为底的方式会抓取「触发瞬间」的整屏画面作为底图
- 抓取的画面只存在于程序内存里，遮挡结束立即断开引用交给 GC —— 全程不写入任何文件、不联网。实测完整运行一轮（含触发）后，程序目录与临时目录新增文件数为 0

---

## 按键计数

- 统计窗口与触发阈值可自由设定，触发后冷却时间可设
- 按住判定的两种模式：
  - **持续按住只算一次** —— 只算真正按下那一下，系统的自动重复会被忽略（默认）
  - **按住算多次** —— 每按住 N 毫秒算一次
- 触发瞬间仍被按住的键，在松开之前不再计入；按键状态会周期性用系统真实键状态校正，不会因为事件丢失而卡在「已按下」
- 定格期间**只屏蔽「按下」、放行「抬起」** —— 前台程序不会残留按键按下状态

---

## 怎么用

1. 双击 `多动症矫正器.exe`。首次运行会在同目录生成 `assets\notice.png` 与 `notice.wav`
2. 调参数，点「最小化并继续监控」，回游戏里玩
3. 界面底部「运行日志」会打印命中的档案、冻结是否成功、错误码

第一次测试建议把阈值调到 4~6 次 / 1000ms。

---

## 注意

1. **窗口化**：用在东方 Project 这类老引擎上，强烈建议开窗口化 / 无边框窗口化运行。独立全屏（DirectX 独占全屏）时覆盖层可能盖不上去，挂起还可能触发显卡驱动超时
2. **窗口太小**：上方面板可以滚动，所有选项都在
3. **权限（很重要）**：目标程序若以管理员身份运行，本程序也必须以管理员身份运行，否则会出现两种**不报错的**失效 —— 它的键盘/鼠标事件收不到（Windows 的 UIPI 限制，未提权的低层钩子看不到提权进程的输入），以及无法挂起它（`OpenProcess(PROCESS_SUSPEND_RESUME)` 被拒绝）。东方联机包（`th09_netplay` 这类带 `adonis` / `SWARM` 的）通常就是用管理员权限启动游戏的。程序检测到这种情况会在界面上提示，也可以点「以管理员身份重启」一键提权重启
4. 内置了东方系列的进程识别档案（th06 / th07 / th08 / th09 / th09c / th11 / th12 / th06nc），命中时会在日志里写明
5. **恢复后画面停住**：恢复时只请求窗口重绘，不阻塞、也不改窗口尺寸。个别程序恢复后画面会静止不动，这时把 `config.json` 里的 `ForceRedrawStrong` 改成 `true` —— 它会额外发一个尺寸不变的 `WM_SIZE` 促使游戏重建 D3D 交换链，能修好停死，代价是恢复瞬间一次短促掉帧（同时开着录屏时更明显）
6. **触发耗时可查**：每次触发后「运行日志」会多打一行 `[计时]`，列出各阶段累计耗时。开录屏时若发现掉帧，看这一行就知道是谁在拖时间 —— 正常应远小于 100 ms

## 设置保存在哪

所有设置都是**自动记住**的 —— 关闭程序时写盘，下次打开直接沿用，不用重新调一遍。

默认存在用户目录：

```
%LOCALAPPDATA%\多动症矫正器\config.json
```

所以换目录、重新解压、升级新版本，设置都不会丢。

如果程序所在目录里也放了一份 `config.json`，则**优先用那一份** —— 这是便携用法：把配置和 exe 放一起，拷贝到哪儿都带着自己的设置。

```
config.json        只有手动放在程序目录里时才会用到（见上）
```

## 命令行自检

```
多动症矫正器.exe --selftest        环境 / 钩子 / 素材 / 权限 / 显示器自检
多动症矫正器.exe --probe 3000      频率检测 + 按键判定逻辑自检
多动症矫正器.exe --suspendprobe    挂起 / 恢复原语自检
多动症矫正器.exe --swallowcheck    吞键行为验证（按下被拦、抬起放行）
多动症矫正器.exe --triggertest     启动 2 秒后自动触发一次（调试用）
多动症矫正器.exe --plan            列出素材实测时长与算出的冻结 / 展示时长
```
